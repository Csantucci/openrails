Open Rails NewYear Weather Editor ORNYMG WE Rev.170 Readme
december 31st, 2025

This pack tentatively integrates ORNYMG rev. 170 with the Weather Editor of ExRail, described here https://www.elvastower.com/forums/index.php?/topic/37959-new-version-of-ornymg-weather-extension-testing-02/ .
It might contain many errors and bugs, as I don't know well the Weather Editor. Please report in the Elvas Tower forum any Weather Editor discrepancy with the original version of ExRail.

The general features of the base ORNYMG Rev. 170 can be found in the related Readme file.
