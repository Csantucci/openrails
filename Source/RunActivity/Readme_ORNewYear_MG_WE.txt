Open Rails NewYear Weather Editor ORNYMG WE Rev.175.1 Readme
October 10th, 2026

This pack integrates ORNYMG rev. 175.1 with the Weather Editor of ExRail, described here https://www.elvastower.com/forums/index.php?/topic/37959-new-version-of-ornymg-weather-extension-testing-02/ .
It might contain some errors and bugs, as I don't know well the Weather Editor. Please report in the Elvas Tower forum any Weather Editor discrepancy with the original version of ExRail.

The general features of the base ORNYMG Rev. 175.1 can be found in the related Readme file.
