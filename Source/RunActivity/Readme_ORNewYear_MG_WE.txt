Open Rails NewYear Weather Editor ORNYMG WE Rev.164 Readme
May 20th, 2025

This pack tentatively integrates ORNYMG rev. 164 with the Weather Editor of ExRail, described here https://www.elvastower.com/forums/index.php?/topic/37959-new-version-of-ornymg-weather-extension-testing-02/ .
It might contain many errors and bugs, as I don't know well the Weather Editor. Please report in the Elvas Tower forum any Weather Editor discrepancy with the original version of ExRail.

The general features of the base ORNYMG Rev. 164 can be found in the related Readme file.
